# RewangOS UI direction

Reading this as: a local worker directory for Solo Raya households, in a warm regional editorial style, dial ENERGY 2 / RHYTHM 2 / MOTION 1.

## Identity

- Forest green (`#193b2e`) anchors the service in a calm, local tone.
- Warm cream (`#f5f0e6`) is the reading surface for a directory used to compare practical details.
- Honey gold (`#e9b94f`) carries the regional identity and highlights a small amount of key information.
- Terracotta (`#a73c27`) is the action accent for search and contact actions.
- Green and red status colors appear only to distinguish available from busy profiles.
- DM Serif Text gives page headings an editorial voice; DM Sans keeps search, pricing, and profile details easy to scan.

## Composition and interaction

- The worker directory uses a comparison grid because people choose between profiles using category, area, availability, and rate.
- Package options have equal visual weight because the UI has no evidence that one option should be recommended over another.
- The process section has three stages because the current demo flow is search, local credit simulation, then WhatsApp contact.
- Profile details use a dialog so a person can inspect one worker without losing the directory filters.
- The sticky header uses one restrained translucent green surface so its controls stay legible while retaining a little context from content moving beneath it.
- Map, clock, phone, wallet, and star icons identify location, availability, contact, credit, and rating respectively.
- Motion stays at hover and pressed feedback. It keeps controls responsive without moving content during comparison.

## Data honesty

- Availability, rates, ratings, and reviews come from worker profile rows.
- Credit purchase and contact unlock are browser-local demo behavior. The UI labels this clearly and does not present a generated pattern as a QR payment.
- Response-time, distance, verification-method, and contact-guarantee claims are omitted unless the product can provide evidence and an operational path.
